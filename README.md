# Privacy Checkup

Connect your Google or Microsoft account, run one check, and see only what needs fixing:
files shared too widely, security emails you missed, and leaked passwords, each with
"fix it now" and "avoid it next time" advice.

- `PRD.md`: the product spec.
- `ui/`: the current front end (static HTML/CSS/JS). Run it locally with `node ui/serve.js`,
  then open http://localhost:4321.

Status: front-end prototype. Real Google sign-in and scanning are next.
